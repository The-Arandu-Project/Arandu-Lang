# Warning W008: Legacy Annotation Name

This warning occurs when source code uses a temporary compatibility spelling
for a built-in annotation. The legacy name still has the canonical semantics
during the migration window, but it will be removed at a documented version
boundary.

```arandu
@no_fallback
func critical() {}
```

Use the canonical PascalCase spelling:

```arandu
@NoFallback
func critical() {}
```

The diagnostic includes a structured replacement for only the annotation
identifier, so editors can apply the migration without changing `@`, arguments,
comments, or surrounding whitespace.
