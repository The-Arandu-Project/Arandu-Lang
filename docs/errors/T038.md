# Error T038: Integer Literal Out of Range

An integer literal cannot be represented by the integer type required by its
context. Arandu checks literals at assignments, arguments, returns and other
locations that provide an expected type.

For example, `256` does not fit in `u8`:

```arandu
let value: u8 = 256
```

Use a wider type or choose a value within the destination type's range:

```arandu
let value: u16 = 256
```

This conversion applies only to literals. Arandu does not implicitly convert
already-materialized variables or arbitrary numeric expressions.
