# Error T035: Invalid Destructor Contract

This error occurs when `@Destructor` is attached to a method that cannot serve
as the unique cleanup operation for its receiver type.

A destructor must be a synchronous nominal-type method with exactly one
`own self` parameter and a `void` result. A type may declare only one such
method. The annotation, rather than the method name or the presence of pointer
fields, establishes the ownership contract.

```arandu
@Destructor
func Resource.close(own self): void {
    // release resources owned by self
}
```

Use an ordinary unannotated method when the operation only borrows or mutates
the receiver without ending its lifetime.
