# Error N012: Unknown Annotation

This error occurs when an annotation name is not part of Arandu's built-in
annotation registry, or when the name is reserved for a feature whose semantics
are not implemented yet.

Annotation names are case-sensitive. The compiler does not normalize spelling
or silently activate planned annotations.

```arandu
@Nofallback
func critical() {}
```

Use an available canonical annotation name:

```arandu
@NoFallback
func critical() {}
```
