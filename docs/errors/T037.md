# Error T037: Invalid Benchmark Contract

`@Benchmark` may only annotate a synchronous, non-generic free function whose
signature is `func name(mut bench: testing.Benchmark): void`.

The benchmark context owns warmup, calibration and measurement. Accepting a
different signature would make the measured region ambiguous or bypass the
runner's iteration controls.

Change the function signature to the supported contract, or remove
`@Benchmark` when the function is not a benchmark entry point.
