# Error T039: Unsatisfied or Denied Effect

A function performs an effect that is not declared in its `@Effects(...)`
annotation, or performs an effect that is denied by the package manifest
(`policy.effects.deny`).

For example, reading a file requires declaring the `FileRead` effect:

```arandu
@Effects(FileRead)
func readConfig(path: str): Result<String, IoError> {
    return fs.readToString(path)
}
```

If `@Effects` is omitted or does not include `FileRead`, or if the package
manifest specifies `deny = ["FileRead"]`, the compiler rejects the function.

Declare the required effects in the function signature:

```arandu
@Effects(FileRead, FileWrite)
func updateConfig(path: str, data: []u8): Result<void, IoError> {
    // ...
}
```

If the effect is denied by the project manifest, ensure that the package policy
allows the capability before performing host operations.
