# Error T040: Division By Zero

An arithmetic expression attempts to divide or compute the remainder (`%`) with
a literal divisor of zero. Arandu rejects division by zero at compile time whenever
the divisor is known to be zero.

For example, dividing by zero:

```arandu
let x = 42 / 0
```

Or computing the remainder with zero:

```arandu
let y = 10 % 0
```

## How to Fix

Ensure that the divisor is non-zero, or handle zero values with a conditional
check:

```arandu
let x = 42 / 2
```
