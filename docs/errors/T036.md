# Error T036: Invalid Test Contract

This error occurs when `@Test` marks a function whose signature cannot be
called safely and deterministically by the generated test harness.

In the first testing contract, a test must be a synchronous, non-generic free
function with no parameters. It may return `void` or `Result<void, E>`.

```arandu
@Test
func parsesHeader(): void {
    // assertions
}
```

Methods require an instance, parameters require an undisclosed source of
arguments, and async functions require the future runtime test contract. Remove
`@Test` or change the function to one of the supported signatures.
