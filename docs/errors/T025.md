# Error T025: Interface Not Satisfied

A generic type argument does not satisfy a required interface bound. Arandu
checks the required method signatures structurally; no explicit implementation
block is needed.

## Incorrect Code Example

```arandu
interface Job<R> {
    func run(shared self): R
}

func consume<J: Job<int>>(job: J): void {}

func forward<J: Job<bool>>(job: J): void {
    consume<J>(job)
}
```

## Semantic Explanation

A bound on a type parameter is a guarantee available while checking a generic
function. `Job<bool>` does not establish `Job<int>`: the interface identity and
its type arguments must match. This also applies to nested arguments such as
`Job<Option<int>>` and `Job<Option<bool>>`.

Bounds that refer to other parameters are substituted at the call site. For
example, calling a function with parameters `<R, J: Job<R>>` using `<int, J>`
requires `J: Job<int>`.

For concrete types, the compiler checks the methods required by the instantiated
interface. For a generic parameter, the caller must declare the corresponding
bound; an unrelated instantiation of the same interface is insufficient.

## How to Fix

Make the forwarded contract agree with the callee:

```arandu
interface Job<R> {
    func run(shared self): R
}

func consume<J: Job<int>>(job: J): void {}

func forward<J: Job<int>>(job: J): void {
    consume<J>(job)
}
```

If the operation should support multiple result types, make that result a type
parameter and forward it consistently instead of imposing an incompatible bound.

For the canonical `std.core.marker.Send` and `Sync` interfaces, an empty method
list does not satisfy the bound automatically. The compiler checks a conservative
owned-storage subset, including nested fields and generic arguments. Borrowed
views, raw pointers, coroutine state, cooperative task handles and resources
with destructors are not admitted. Copying a view does not extend its owner's
lifetime. Use eligible owned data or keep the operation within its current
execution context until the required transfer/lifetime contract is supported.
