# Error O010: Escape of Borrowed Value

This error occurs when a safe borrowed return would outlive a local owner, or
when the compiler cannot demonstrate a bounded dependency on a caller-owned
formal input. The compiler rejects the program instead of fabricating
provenance or silently promoting a projected view.

## Incorrect Code Example

```arandu
func getRef(): ref int {
    let value = 5
    return ref value // the owner dies when getRef returns
}
```

## Semantic Explanation

Stack-allocated local variables are destroyed when their function returns.
Borrow interfaces are inferred from typed AMIR flow and may refer only to
formal `ref`/`mut ref` inputs. Type compatibility alone is not proof. Structural
contracts are also bounded; an excessive or unrepresentable path fails closed.

## How to Fix

Return the owned value, or forward a borrow whose owner remains in the caller:

```arandu
func getValue(): int {
    let value = 5
    return value
}

func identity(value: ref int): ref int {
    return value
}
```
